## CODING REPO PATTERNS AND RULES:
- Always use codegraph. If codegraph is not available, initialize it with `codegraph init` and then run `codegraph sync` to generate the codegraph.
- Always check code using `pnpm build`, `pnpm check`, `pnpm test` and `pnpm test:e2e` before finishing a PR.
- Always push changes to engram.
- Always use `pnpm` to install dependencies. Do not use `npm` or `yarn`.
- Always use `pnpm` to run scripts. Do not use `npm` or `yarn`.
- Always use skill gentleman-orchestrator to manage your codebase.
- Always use hexagonal architecture to structure your codebase.
